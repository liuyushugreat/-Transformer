引言与背景

Introduction & Background
🎯 论文问题：RNN 逐位置串行计算，无法并行、长序列梯度难传播。Transformer 用「纯注意力」替换循环，完全并行化。
▾
🧩 论文要点
💡一句话理解：论文把「序列建模」从「按时间顺序一步步算」变成「所有位置同时互相看」，这是 Transformer 一切优点的根源。

缩放点积注意力

Scaled Dot-Product Attention (3.2.1)
🎯 论文要点：注意力 = 对 Value 的加权求和，权重由 Query 与 Key 的相似度决定。除以 $\sqrt{d_k}$ 防止点积过大。
▾
🧩 论文要点
📐 核心公式（论文式 1）
缩放点积注意力
$$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

多头注意力

Multi-Head Attention (3.2.2)
🎯 论文要点：把 Q/K/V 线性投影 h 次，并行做注意力，拼接后再投影。让模型从不同表征子空间联合关注信息。
▾
🧩 论文要点
📐 核心公式（论文式 2）
多头注意力
$$\text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O,\quad \text{head}_i=\text{Attention}(QW_i^Q,KW_i^K,VW_i^V)$$

位置编码

Positional Encoding (3.5)
🎯 论文要点：模型没有循环/卷积，需注入位置信息。用不同频率的正弦/余弦函数作为位置编码，加到嵌入上。

🎯 论文要点：从计算复杂度、可并行度、长依赖路径长度三个维度，对比自注意力 vs 循环 vs 卷积。

核心公式速查

论文全部 3 个公式 + 多头注意力公式，记住它们就掌握了 Transformer 的数学本质。

① 缩放点积注意力（式 1）
$$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
② 多头注意力（式 2）
$$\text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O$$
③ 位置前馈网络（式 2）
$$\text{FFN}(x)=\max(0,\;xW_1+b_1)\,W_2+b_2$$
④ 位置编码（式 3）
$$PE_{(pos,\,2i)}=\sin\!\Big(pos/10000^{2i/d_{model}}\Big),\qquad PE_{(pos,\,2i+1)}=\cos\!\Big(pos/10000^{2i/d_{model}}\Big)$$
⑤ 学习率调度（式 4）
$$lrate = d_{model}^{-0.5}\cdot\min\!\Big(step\_num^{-0.5},\ step\_num\cdot warmup\_steps^{-1.5}\Big)$$
⑥ 残差 + LayerNorm
$$\text{Output}=\mathrm{LayerNorm}\big(x+\mathrm{Sublayer}(x)\big)$$
