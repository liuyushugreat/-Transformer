# 一句话读懂 Transformer

> 以「我要吃苹果」的中译英为例，从原理到完整代码，手把手从零实现一个 Transformer。

本仓库围绕一句中文 **「我要吃苹果」 → 「i want to eat an apple」**，把 Transformer 的每个组件（分词、嵌入、位置编码、自注意力、多头注意力、前馈网络、残差连接、层归一化、编码器、解码器、训练与推理）讲清楚，并配上一份**不依赖 `nn.Transformer`、可从零跑通**的完整 PyTorch 代码。

## 🚀 快速开始

### 环境要求

- Python 3.8+
- PyTorch 1.12+

全部代码在普通笔记本 **CPU** 上约 1 分钟即可训练完毕，**无需 GPU**。

### 安装依赖

```bash
pip install torch
```

### 运行

```bash
python transformer_zh2en.py
```

运行后会自动：

1. 用 22 条迷你中英平行语料训练一个 Transformer；
2. 打印每个 epoch 的 loss（最终约 0.63，因标签平滑不会降到 0）；
3. 逐步追踪「我要吃苹果」的逐词生成过程（`i → want → to → eat → an → apple`）；
4. 可视化最后一层解码器的**交叉注意力**，看每个英文词对齐到哪个中文词；
5. 测试更多句子，例如 `她 要 吃 苹果`、`我 不 要 喝 牛奶` 等。
